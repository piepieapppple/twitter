# X RT 랜덤 추첨기 (웹앱)

아이패드/휴대폰 브라우저에서 쓸 수 있는 간단한 웹앱입니다.
- X 게시물 링크 입력
- RT 계정 페이지 조회
- 중복 제거
- 무작위 당첨자 추첨
- 참여자 및 당첨자 CSV 저장

## 중요한 점
이 프로젝트는 프런트엔드와 서버리스 API 코드를 포함한 **배포용 초안**입니다. 파일만 열어서는 실제 RT 목록을 불러올 수 없습니다. Vercel 등에 배포하고 API 키를 서버 환경변수로 설정해야 합니다. API 키를 `index.html`에 넣거나 공개 저장소에 올리지 마세요.

## API 제공자
현재 서버 코드는 TwitterAPIs의 `GET https://api.twitterapis.com/twitter/tweet/retweeters` 엔드포인트를 사용합니다. API 키가 필요하며 호출마다 과금될 수 있습니다. 서비스 가격/한도는 가입 전 공식 문서에서 확인하세요.

## 배포 개요
1. GitHub 계정에서 새 저장소를 만듭니다.
2. 이 ZIP의 파일을 저장소 루트에 업로드합니다. `api/reposters.js`는 `api` 폴더 안에 둡니다.
3. Vercel에서 해당 GitHub 저장소를 Import합니다.
4. Vercel 프로젝트의 Settings → Environment Variables에서 `TWITTERAPIS_KEY` 이름으로 API 키를 추가합니다.
5. Deploy를 실행하고 생성된 사이트 주소를 iPad Safari에서 엽니다.

## 확인할 점
- API 응답 필드/페이지네이션은 제공자 문서와 실제 응답에 따라 조정이 필요할 수 있습니다.
- 게시물의 실제 RT 목록이 API 제공자에서 완전하게 제공되는지 먼저 소규모 테스트를 하세요.
- 조회 결과가 일부이거나 API 오류가 나면 추첨을 진행하지 말고 먼저 목록 완전성을 확인하세요.
- 추첨은 브라우저의 무작위 선택을 사용합니다. 공식/감사 가능한 난수 추첨 인증을 제공하지 않습니다.
- 이 도구는 인용 RT/Quote posts가 아니라 직접 리포스트한 계정을 대상으로 합니다.
